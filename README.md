# 천안시 사랑의 줄눈 봉사활동 — 인터랙티브 웹 프레젠테이션

원본 6장 슬라이드를 고해상도 이미지로 유지하면서 화면 이동, 애니메이션, 전체 슬라이드 목차, 확대 보기, 텍스트 접근성, 키보드·터치 탐색을 추가한 정적 웹사이트입니다.

## 열어보기

`index.html`을 브라우저에서 열거나 GitHub Pages에 게시하면 됩니다. 서버, 데이터베이스, 빌드 도구, 외부 CDN이 필요하지 않습니다.

## GitHub Pages 게시하기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `assets/`, `.nojekyll`을 저장소의 최상위에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main / (root)**를 선택하고 저장합니다.
4. 표시되는 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## 사용법

- 화면 하단 **이전 / 다음** 버튼, 상단 메뉴를 눌러 이동
- 마우스 스크롤, 모바일 위아래 스와이프, 키보드 `← → ↑ ↓`, `PageUp`, `PageDown`, `Space`, `Home`, `End`로 이동
- 우측 상단 격자 메뉴로 전체 슬라이드 미리보기 (`G` 키)
- 돋보기 모양 버튼 또는 슬라이드 이미지를 눌러 확대
- **텍스트로 자세히 보기** 버튼에서 슬라이드 원문 읽기
- 전체 화면 버튼으로 발표 모드 전환 (브라우저 지원 시)

## 파일 구조

```
index.html
.nojekyll
assets/
  slide-1.jpg
  slide-2.jpg
  slide-3.jpg
  slide-4.jpg
  slide-5.jpg
  slide-6.jpg
```

모든 경로는 상대 경로(`assets/slide-N.jpg`)이므로 GitHub Pages 프로젝트 사이트 하위 경로에서도 작동합니다.

## 원본 보존 관련

원본 PPTX의 내용, 일러스트, 도식과 배치를 슬라이드별 이미지로 렌더링해 누락 없이 제공합니다. 원본의 개별 도형이나 차트를 HTML 편집 요소로 분해하지는 않았습니다. 웹 상호작용은 화면 이동, 확대, 미리보기 및 텍스트 조회 중심입니다.
